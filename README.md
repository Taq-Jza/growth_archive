# 成长档案 · 校园个人成长与求职助手

把大学里散落的课程、技能、竞赛、项目、特长记成「成长记录」。
求职时粘贴一段岗位 JD，系统从档案里匹配证据、指出缺口，并生成能直接写进简历的条目 —— 每一句都能点回原始记录。

---

## 一、它解决什么问题

大学四年里值得写进简历的东西，散落在微信群、网盘、纸质笔记和记忆里。平时没人记，求职时想不起来，简历上只剩「熟练使用 Office」。

「成长档案」做三件事：

1. **记下来** —— 课程、技能、竞赛、项目、特长统一记成带类型和时间的记录；
2. **问得着** —— 对自己的档案提问，答案带出处，可点回原文核对；
3. **用得上** —— 粘贴 JD，匹配证据、指出缺口、生成简历条目。

## 二、几个关键设计

| 常见做法 | 本项目的做法 |
|---|---|
| 存资料，靠搜索找回 | 存**带类型的成长证据**，按类型/时间筛选，五个分类各有独立页面 |
| 只做关键词检索 | **关键词 + 语义双路召回，RRF 融合**：说「自然语言处理」也能找到《文本情感分类实验》 |
| 让 AI「帮我写简历」 | **先检索证据，再改写措辞**；每条都能追溯到记录 ID |
| 匹配度由模型打分 | 三维规则加权计算（0.4/0.4/0.2），**可手算复现** |
| 缺什么靠猜 | 缺口必须引用 JD 原文，并注明「暂无相关记录」 |
| 简历写完就完事 | **面试追问预演**：标出哪些问题你其实答不上来，反向暴露记录缺的细节 |
| 课程答疑胡编 | 课程助手的**每句解释必须挂资料编号**，没编号直接丢弃 |

核心不可妥协的三条：
1. 简历条目里的数字、奖项、时间必须能在原文中找到，否则丢弃；
2. 课程助手不得用课外知识补全，资料没讲就直说；
3. 所有派生数据（切片、索引、向量、要点卡）必须能从原文重建。

## 三、技术栈

| 层 | 选择 |
|---|---|
| Web | FastAPI + Jinja2 + HTMX（服务端渲染，无前端构建） |
| 存储 | SQLite（业务表 + FTS5 全文索引 + 向量列） |
| 中文检索 | jieba 侧分词 → FTS5 unicode61 |
| 语义检索 | bge-m3（1024 维）+ 全量余弦 + RRF 融合 |
| 生成 | OpenAI 兼容接口（Qwen 系列） |
| 部署 | 单机 uvicorn，无外部依赖 |

规模假设：单用户、数十至数百条记录、千级切片。SQLite 在此量级下比引入 PostgreSQL 更合适；
迁移路径见 `specs/001-growth-archive/design.md` 的 D-01。

## 四、规格驱动开发

本项目按「规格 → 设计 → 任务 → 实现 → 验收」推进，四份文档构成一条可追溯的链：

```
需求规格 spec.md  →  设计方案 design.md  →  任务清单 tasks.md  →  编码实现 app/
        ↑                                                          ↓
        └────────────────  验收记录 verification.md  ←──────────────┘
```

- 每条需求编号 `F-xx`，对应设计决策 `D-xx`、任务 `T-xx`、验收项 `AC-xx-y`；
- **可追溯矩阵**在 `design.md` 第 7 节：任一条需求都能顺到设计、任务、代码文件与验收编号；
- 规格变更记在 `spec.md` 的修订记录里，验收表按版本整体重排，不留过期行。

## 六、跑起来

见 `run.md`。最短路径：

```bash
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
cp .env.example .env          # 填 LLM_API_KEY
.venv/Scripts/python.exe -m uvicorn app.main:app --reload --port 8000
```

打开 http://127.0.0.1:8000 ，点「直接体验，不用注册」。

## 七、页面一览

| 路径 | 说明 |
|---|---|
| `/` | 概览：一句话记录、能力分布饼图、要点卡、全部记录 |
| `/c/{kind}` | 五个分类页（course / skill / award / project / trait），各自呈现方式不同 |
| `/cards` | 全部要点卡，按来源记录分组，可按类型筛选 |
| `/course/question` | 课程助手：问题分析（知识点 / 分步解释 / 资料缺口） |
| `/doc/{id}` | 记录详情，含要点提炼、面试预演、编辑入口 |
| `/doc/{id}/interview` | 面试追问预演 |
| `/search` | 检索，支持类型与时间范围筛选 |
| `/ask` | 带引用问答，可用 `?scope=course` 限定范围 |
| `/match` | 岗位匹配与简历条目 |
| `/new` | 添加资料（文件上传 / 拍照 / 粘贴文本） |
